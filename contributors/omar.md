# Omar

![](omar.png)

**Role:** Software engineering — frontend, backend, APIs

I write code for a living, and I read it before I touch it, because a project that already works deserves respect and a diff I can't explain is a diff I shouldn't ship. I'm usually the one asking "prove it" — show me the failing test, show me the real output, not the version you expected to see. I care about the boring things that keep a team moving: interfaces that say what they mean, errors that tell you something true, and tests that fail for the right reason. If something only runs on my machine, then it doesn't run yet, and I'd rather say that out loud than quietly hope nobody asks.
